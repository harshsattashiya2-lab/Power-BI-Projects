## 📌 Project Overview

This project is an **interactive Power BI dashboard** developed to transform raw data into meaningful business insights.

The dashboard uses **data cleaning, transformation, data modeling, DAX calculations, KPIs, and interactive visualizations** to analyze business performance and present the results in an easy-to-understand format.

The project demonstrates practical skills in **Business Intelligence, Data Analytics, Power BI, and Data Visualization**.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze raw business data.
* Clean and transform data using Power Query.
* Create an effective data model.
* Develop meaningful KPIs using DAX.
* Analyze sales and business performance.
* Identify important trends and patterns.
* Create an interactive and user-friendly dashboard.
* Present data-driven insights for better decision-making.

## 🚀 How to Run the Project

### 1️⃣ Install Power BI Desktop

Download and install **Microsoft Power BI Desktop**.

### 2️⃣ Clone the Repository

```bash
git clone https://github.com/harshsattashiya2-lab/Power-BI-Projects.git
```

### 3️⃣ Open the PBIX File

Open:

```text
power_BI_Projects.pbix
```

using Power BI Desktop.

### 4️⃣ Update Data Source

If the dataset is stored locally, update the data source path if required.

### 5️⃣ Refresh the Data

Click:

**Home → Refresh**

to load the data.
